# Diablo IV – Kompendium

Statische Web-Projektkopie des aktuellen Sites-Stands.

## Struktur

- `index.html` – Startseite
- `klassen.html` – Klassenübersicht
- `klassen/` – Detailseiten der Klassen
- `css/` – alle Stylesheets
- `js/` – JavaScript der Startseite
- `img/` – Bilder, Texturen, Ornamente und die Diablo-Schriftdatei

## Lokal öffnen

Für eine schnelle Vorschau kann `index.html` direkt im Browser geöffnet werden.
Empfohlen ist ein kleiner lokaler Webserver, zum Beispiel:

```powershell
npx serve .
```

Danach die angezeigte lokale Adresse im Browser öffnen.
